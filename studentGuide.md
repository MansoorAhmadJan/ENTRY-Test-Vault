# Entry-Test Knowledge Vault — Student Guide

Welcome to the Entry-Test Knowledge Vault.

This is an offline study resource designed to help students find,
organize, and use entry-test preparation resources.

## 🚀 Getting Started

### Option 1 — Download from GitHub

1. Go to the repository.
2. Click **Code**.
3. Click **Download ZIP**.
4. Extract the ZIP file.
5. Open the extracted folder.
6. Double-click `index.html`.
7. The Vault will open in your browser.

No Node.js, Git, or server is required for normal offline use.

## 🔎 Finding Resources

Use the search bar to find resources by:

- University
- Entry test
- Subject
- Topic
- Resource type
- Keywords

You can also use the available filters to narrow down the results.

## ⭐ Favorites and Bookmarks

Use Favorites/Bookmarks to save resources that you want to return to later.

## 📝 Notes and Study Goals

Use the workspace features to:

- Set study goals
- Track your progress
- Write personal notes

## 📊 Progress

Use the progress/analytics features to see how your study activity is developing.

## 💾 Your Data

Student-specific information such as notes, favorites, and progress is stored locally in your browser.

If you clear your browser's site/local storage, this information may be removed.

## 🌐 Internet Requirement

The Vault is designed to work offline.

You may need internet access separately when opening external resources
such as websites, videos, or online courses.

## ❓ Need Help?

If something does not work, first:

1. Refresh the page.
2. Make sure you extracted the complete ZIP.
3. Make sure you are opening the correct `index.html`.
4. Try a modern browser such as Chrome or Edge.
